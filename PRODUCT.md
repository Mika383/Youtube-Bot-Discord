# Product

## Register

product

## Users

Members of a Discord server who listen to music together in a voice channel and need fast, low-friction playback controls in the accompanying text channel.

## Product Purpose

Ringo provides reliable shared YouTube music playback, queue management, and personal playlists inside Discord. Success means users can start music quickly, understand the current playback state at a glance, and control the session without searching through old messages.

## Brand Personality

Compact, lively, and dependable. Copy should be direct Vietnamese with familiar Discord and media-player conventions.

## Anti-references

- Text-heavy control panels that bury the current track.
- Decorative layouts that compete with Discord's native interface.
- Ambiguous toggles whose active state is visible only through button labels.
- Repeated bot messages that leave multiple active control panels in chat.

## Design Principles

- Keep the active controls at the point of conversation.
- Make playback state understandable in one glance.
- Use familiar media icons and predictable Discord interactions.
- Prefer responsive feedback without frequent background message edits.
- Keep one authoritative control panel per guild session.

## Accessibility & Inclusion

Use clear state text in the embed in addition to button color. Disable unavailable actions, keep destructive actions visually distinct, and provide concise Vietnamese feedback for denied or failed actions.
